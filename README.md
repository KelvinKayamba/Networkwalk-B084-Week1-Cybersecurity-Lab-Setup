# Networkwalk-B084-Week1-Cybersecurity-Lab-Setup

# 📌 Project Overview

This project involved completing six browser-based Security Operations Center (SOC) investigation labs through NetworkWalks. The exercises focused on analysing network traffic, investigating suspicious activity, examining network communications, and identifying common security threats.

# Status: Completed all six labs and 60 investigation tasks.

# 🎯 Project Objectives

- Analyse network traffic to identify suspicious IP addresses.

- Reconstruct network conversations using TCP stream analysis.

- Investigate hidden information in captured traffic.

- Identify credentials transmitted in clear text over HTTP.

- Recognise patterns associated with brute-force attacks.

- Investigate VoIP traffic and suspected scam calls.

# 🛠️ Tools and Resources

- Wireshark: Network protocol analysis and packet inspection.

- NetworkWalks: Browser-based cybersecurity training labs.

- PCAP files: Captured network traffic used for investigation.
